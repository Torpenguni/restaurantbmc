# Business Model Canvas

ยังไม่ได้เริ่มเขียนโค้ด — ไฟล์นี้บันทึกไว้ก่อนว่าทำไมถึงแยกรีโป

## ทำไมไม่รวมกับ penguinx-website

ไม่ใช่เรื่องความเป็นระเบียบ แต่เป็นเพราะรีโปนั้นมีสคริปต์ที่จะไปยุ่งกับ
ไฟล์ใหม่โดยอัตโนมัติ

1. **Vercel เสิร์ฟทั้งรีโป** — ไม่มี `vercel.json` กำหนดขอบเขต ไฟล์ HTML
   ใหม่ที่วางลงไปจะโผล่บน penguinx.co ทันทีที่ push
2. **`build-i18n.py` กวาด `**/*.html` ทั้งรีโป** — หน้าใหม่จะถูกแปลเป็น
   ไทย จีน ญี่ปุ่นให้เองทั้งที่ไม่ได้ตั้งใจ แล้วคำที่ไม่มีในไฟล์แปลจะ
   ออกมาเป็นภาษาปนกัน
3. **`build-sitemap.py` กวาดแบบเดียวกัน** — หน้าใหม่จะเข้า sitemap ของ
   penguinx.co ที่ส่งให้ Google Search Console ไว้แล้ว ทำให้ Google เก็บ
   หน้าที่ยังไม่พร้อมไปจัดอันดับปนกับเว็บหลัก
4. **คนละโดเมน คนละกลุ่มเป้าหมาย** — แยกรีโปแล้วต่อ Vercel project ใหม่
   ได้เลย ไม่ต้องแก้อะไรในเว็บเดิม และพังคนละที่

ถ้าจะรวมจริง ๆ ต้องไปเขียน `vercel.json` กำหนด path ใหม่ แก้ทั้งสอง
สคริปต์ให้ยกเว้นโฟลเดอร์นี้ และแยก sitemap — งานมากกว่าและเสี่ยงกว่า
การเริ่มรีโปใหม่

## สถานะ

รอสรุปว่าจะทำอะไร: เครื่องมือให้กรอก canvas / หน้าให้ความรู้ + เทมเพลต /
ทั้งสองอย่าง และจะใช้ภาษาอะไรบ้าง
