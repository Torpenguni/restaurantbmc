# RestaurantBMC

Business Model Canvas สำหรับร้านอาหาร

เว็บภาษาไทยล้วน สำหรับเจ้าของร้านอาหารในไทย มีสองส่วน

| ไฟล์ | คืออะไร |
|---|---|
| `index.html` | หน้าให้ความรู้ — Canvas คืออะไร, 9 ช่องต้องตอบอะไร (คำถามเขียนใหม่ให้ตรงกับร้านอาหาร), ตัวอย่างร้านจริงสองขนาด |
| `canvas.html` | เครื่องมือกรอก 9 ช่อง เซฟอัตโนมัติใน localStorage สั่งพิมพ์เป็น PDF ได้ |
| `styles.css` | สไตล์ทั้งเว็บ |
| `fonts/` | Anuphan เก็บไว้เอง ไม่ดึงจาก Google |

## ที่ต้องตัดสินใจก่อนขึ้นจริง

**ยังไม่มีโดเมนและยังไม่ได้ต่อ Vercel** — ดูหัวข้อ "เอาขึ้นเว็บ" ข้างล่าง

## ทำไมแยกจาก penguinx-website

ไม่ใช่เรื่องความเป็นระเบียบ แต่เพราะรีโปนั้นมีสคริปต์ที่จะไปยุ่งกับไฟล์ใหม่เอง

1. **Vercel เสิร์ฟทั้งรีโป** — ไม่มี `vercel.json` กำหนดขอบเขต ไฟล์ HTML ใหม่จะโผล่บน penguinx.co ทันทีที่ push
2. **`build-i18n.py` กวาด `**/*.html` ทั้งรีโป** — หน้าใหม่จะถูกแปลเป็นไทย จีน ญี่ปุ่นให้เอง คำที่ไม่มีในไฟล์แปลจะออกมาเป็นภาษาปนกัน
3. **`build-sitemap.py` กวาดแบบเดียวกัน** — หน้าใหม่จะเข้า sitemap ของ penguinx.co ที่ส่ง Google Search Console ไว้แล้ว
4. **คนละแบรนด์ คนละกลุ่มเป้าหมาย** — แยกแล้วพังคนละที่ และแก้เว็บนี้ไม่กระทบ penguinx.co

## เอาขึ้นเว็บ

ยังไม่ได้สร้างรีโปบน GitHub เพราะเครื่องนี้ไม่มี `gh` CLI ทำได้สองทาง

**ทางที่ 1 — ผ่าน GitHub**
1. สร้างรีโปเปล่าชื่อ `restaurantbmc` ที่ github.com/new (ไม่ต้องติ๊ก README)
2. รันคำสั่งนี้

```bash
cd ~/Documents/restaurantbmc
git remote add origin https://github.com/Torpenguni/restaurantbmc.git
git branch -M main
git push -u origin main
```

3. เข้า vercel.com → Add New → Project → เลือกรีโปนี้ → Deploy (ไม่ต้องตั้งค่าอะไร เป็น static ล้วน)

**ทางที่ 2 — ขึ้น Vercel ตรงจากเครื่อง** ไม่ต้องใช้ GitHub

```bash
cd ~/Documents/restaurantbmc
npx vercel
```

## หมายเหตุทางเทคนิค

- ไม่มี build step ไม่มี dependency เปิดไฟล์ผ่าน web server ก็ใช้ได้เลย
- เครื่องมือกรอกใช้ `localStorage` คีย์ `bmc-restaurant-v1` — ข้อมูลอยู่ในเครื่องผู้ใช้ ไม่ส่งไปไหน ไม่มีฐานข้อมูล ไม่มีการเก็บข้อมูลส่วนบุคคล
- ตอนสั่งพิมพ์ สคริปต์จะยืด `<textarea>` ทุกช่องให้พอดีเนื้อหาก่อน ไม่งั้นข้อความส่วนที่เกินขอบจะหายไปในไฟล์ PDF
- ทดสอบแล้วที่จอ 320 / 360 / 390 / 768 / 1024 / 1280 ไม่ล้นแนวนอนทั้งสองหน้า

## ความเห็นเชิงลึกจาก AI (ต้องตั้งค่าเพิ่ม)

ปุ่ม "ส่งไปให้ AI อ่าน" ในหน้ากรอก เรียก `api/review.js` ซึ่งเป็น Vercel
Serverless Function ตอนนี้โค้ดพร้อมแล้วแต่ยังไม่ทำงาน เพราะยังไม่มี API key

**เปิดใช้ยังไง**

1. สร้าง API key ที่ console.anthropic.com → API Keys
2. **ตั้ง spend limit ในคอนโซลด้วย** — อันนี้คือด่านเดียวที่กันค่าใช้จ่ายได้จริง
   ตัวจำกัดอัตราในโค้ดเก็บสถานะในหน่วยความจำของ instance ซึ่ง serverless
   สร้างใหม่ได้เรื่อย ๆ จึงเป็นลูกระนาด ไม่ใช่กำแพง
3. Vercel → Project → Settings → Environment Variables เพิ่ม
   - `ANTHROPIC_API_KEY` = key ที่ได้มา
   - `BMC_MODEL` (ไม่ใส่ก็ได้) ค่าเริ่มต้น `claude-haiku-4-5-20251001`
4. Redeploy

ถ้ายังไม่ตั้ง ปุ่มจะขึ้นว่า "ยังไม่ได้ตั้งค่า API key ที่ Vercel" ส่วนที่เหลือของเว็บทำงานปกติ

**ความเป็นส่วนตัว** — ทุกอย่างในเว็บทำงานในเครื่องผู้ใช้ ยกเว้นปุ่มนี้ปุ่มเดียว
ต้องกดเองและมีกล่องยืนยันก่อนส่งทุกครั้งแรก ชื่อร้านไม่ถูกส่งไป
ฝั่งเซิร์ฟเวอร์ไม่บันทึกเนื้อหาลงล็อก

**ด่านที่ใส่ไว้แล้ว** — รับเฉพาะ POST · เช็ค Origin · จำกัด 4 ครั้ง/นาที/IP ·
ตัดข้อความขาเข้าที่ 12,000 ตัวอักษร · เพดาน token ขาออก 1,200 ·
ไม่ส่งข้อความ error จากต้นทางกลับหน้าเว็บ
